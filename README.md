# Soil pH Lime & Sulfur Amendment Calculator
Calculate pounds of lime or sulfur needed to adjust your garden soil pH based on area and soil type.
## Features
- Inputs for current pH, target pH, area in sq ft, and soil type (sandy/loamy/clay)
- Calculates lime needed to raise pH or sulfur needed to lower pH with soil-type multipliers
- Warning banner for pH changes greater than 2.0 units
- Calculation breakdown showing pH difference, multiplier, and base rate
- Application tips for lime and sulfur amendments
## Tech
Static SPA · Tailwind CDN · localStorage
